# 게코노트(GeckoNote) 서비스 기획서

## 1. 서비스 개요

| 항목 | 내용 |
|---|---|
| 서비스명 | 게코노트 (GeckoNote) |
| 목적 | 크레스티드 게코(크레스티드 도마뱀)를 키우는 사용자가 자신의 게코 정보를 등록·관리하고, 사진을 통해 모프(무늬·색상 패턴)를 AI로 분석받을 수 있는 웹 서비스 |
| 타겟 사용자 | 크레스티드 게코를 반려동물로 키우는 초보~중급 사육자, 모프 구분에 어려움을 느끼는 사용자 |
| 배포 URL | https://gecko-note-qste.vercel.app |

**기획 배경**

저는 실제로 크레스티드 게코를 7마리 키우고 있습니다. 마리 수가 늘어나면서 각 개체의 이름, 모프, 부모 모프, 나이 같은 정보를 따로 기록해두지 않으면 헷갈리는 상황이 자주 생겼습니다. 특히 모프가 비슷해 보이는 개체가 많아지면서 육안으로 구분하기 어려운 경우도 있었습니다. 게코노트는 이런 다마릿수 사육 환경에서 개체 관리를 좀 더 수월하게 하기 위해 직접 필요성을 느끼고 기획한 서비스입니다.

## 2. 페이지 / 섹션 구성

메뉴를 통해 아래 3개 섹션을 이동할 수 있다.

1. **홈**
   - 서비스 소개
   - 대표 이미지
   - 시작하기 버튼 (다른 섹션으로 이동)

2. **내 게코 등록·목록**
   - 게코 이름, 모프명, 부모 모프, 나이, 사진을 입력하는 등록 폼
   - 등록된 게코를 카드 형태로 보여주는 목록
   - 브라우저 저장(localStorage) 기반으로 데이터 유지

3. **모프 AI 분석**
   - 게코 사진을 업로드하면 AI가 모프(무늬·색상 패턴)를 분석해 설명해주는 기능

## 3. 핵심 기능

- 게코 정보 등록 및 목록 관리
- 사진 기반 모프 AI 분석 (핵심 AI 기능)
- 반응형 레이아웃 (모바일 / 태블릿 / 데스크톱 대응)

## 4. AI 기능 설계 — 모프 AI 분석

| 항목 | 내용 |
|---|---|
| 입력 | 사용자가 업로드한 게코 사진 (이미지 파일) |
| 처리 | Google Gemini API(비전 지원 모델)로 이미지를 전송하여 모프 특징을 분석 |
| 출력 | 예상 모프명, 무늬·색상 특징 설명, 요약 코멘트 |
| 제공 가치 | 사용자가 스스로 판단하기 어려운 모프 구분을 AI의 도움으로 참고할 수 있음 |

### 실패 처리 기준

| 상황 | 처리 방식 |
|---|---|
| 사진 없이 요청 | "사진을 업로드해주세요" 안내 메시지 표시 |
| API 오류(4xx/5xx) | "잠시 후 다시 시도해주세요" 안내 메시지 표시 |
| 응답 지연 | 분석 중 로딩 상태("분석 중...") 표시 |

## 5. 기술 스택

| 구분 | 사용 기술 |
|---|---|
| 프론트엔드 | HTML / CSS / JavaScript (프레임워크 미사용) |
| 백엔드 | Vercel Serverless Functions (Python) |
| AI API | Google Gemini API (비전 지원 모델, 무료 티어) |
| 배포 | GitHub + Vercel |
| 개발 도구 | VS Code, Claude Code (AI 코딩 도구) |

## 6. 개발 과정 요약

VS Code와 Claude Code(AI 코딩 도구)를 활용해 프론트엔드부터 AI 기능 연동, 배포까지 전 과정을 진행했다. 개발 중 아래와 같은 문제를 겪었고 해결했다.

- Windows 환경에서 `vercel dev` 실행 시 경로 문자열이 유니코드 이스케이프로 잘못 해석되는 문제 → 프로젝트 폴더를 단순 경로로 이동하여 해결
- `pyproject.toml` 설정 미비로 인한 Python 함수 인식 실패 → `[project]`, `[tool.vercel]` 섹션과 의존성 명시로 해결
- GitHub 저장소가 비공개(Private) 상태여서 Vercel 무료 플랜에서 배포가 차단됨 → 저장소를 공개(Public)로 전환하여 해결
- 정적 파일과 API 함수 라우팅 충돌 → `vercel.json` 라우팅 설정 수정으로 해결
